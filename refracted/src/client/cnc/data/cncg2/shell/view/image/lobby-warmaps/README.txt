War maps for the Aurora lobby's map stage, one file per map, named after the map's minimap file:

    <minimap name>.jpg      e.g. DM_Monsoon_3v3_MO.jpg      (.png also works)

14:9, ideal 1904 x 1224 (minimum 952 x 612), natural colour. The picture fills the stage (952 x 612 on a
1920x1080 window). A map without a file here shows its square lobby minimap in the middle of the stage.

Names, start pip placement (warFit) and safe areas: "War maps (lobby map stage)" in the shell README.
